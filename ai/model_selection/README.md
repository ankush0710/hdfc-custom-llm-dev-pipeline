# Base Model Selection

## Objective

Select the base language model for the HDFC Custom LLM Pipeline.

## Selection Criteria

1. Model license
2. Model size
3. Hardware requirements
4. Quantization support
5. LoRA/QLoRA compatibility
6. Transformers compatibility
7. Context length
8. Expected inference performance
9. Reproducibility
10. Suitability for the project requirements

## Candidate Models

Candidates will be evaluated before selecting the final base model.
