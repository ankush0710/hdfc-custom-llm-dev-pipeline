# Final Team Roles

| Member | Role | Primary Ownership | Secondary Ownership |
|---|---|---|---|
| Member 1 | AI/ML Lead | Model training, inference, AI integration | AI coordination |
| Member 2 | Data Engineer | Dataset preparation, validation, lineage | AI data quality |
| Member 3 | Full Stack + DevOps | Frontend, backend, deployment | API integration |
| Member 4 | AI Evaluation / QA Engineer | Model evaluation, QA, security/robustness testing | Prompt/testing analysis |
| Member 5 | MLOps Engineer | MLflow, experiment tracking, model/evaluation evidence packaging | MLOps handoff support |
| Member 6 | Documentation Lead | Final README, report, presentation, project documentation | Documentation coordination |

## Ownership rule

Each member owns the technical deliverables assigned above. Member 5 packages and tracks MLOps evidence but does not own the project's general documentation. Member 6 is accountable for the final documentation set.
